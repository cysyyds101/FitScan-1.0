# FitScan - 智能人体尺寸估算系统

## 项目简介
FitScan 是一个基于单目视觉与参照物校准的智能人体尺寸估算系统，利用普通摄像头和已知尺寸的参照物（如 A4 纸、银行卡）来快速测量人体尺寸并推荐服装尺码。

## 核心功能
- **实时视频采集**：使用 OpenCV 调用摄像头，支持多种分辨率设置
- **参照物检测**：自动识别 A4 纸、身份证或银行卡，计算像素与真实长度的比例系数
- **人体关键点提取**：使用 MediaPipe Pose 提取 33 个人体关键点
- **尺寸计算**：肩宽、臂长、腿长、身高、胸围、腰围、臀围
- **体型分析**：雷达图可视化展示人体体型轮廓
- **尺码推荐**：根据测量结果推荐服装尺码（宽松版/修身版）
- **AR 可视化**：实时显示测量数据和骨架，提供直观反馈

### 核心模块说明

#### 1. 参照物检测器 (ReferenceDetector)
- 使用 OpenCV 边缘检测和轮廓识别
- 支持 A4 纸（21cm）、身份证（8.56cm）、银行卡（8.56cm）
- 自动计算比例系数（cm/像素）
- 使用 minAreaRect 精确检测参照物短边

#### 2. 姿态估计器 (PoseEstimator)
- 基于 MediaPipe Pose
- 提取 33 个人体关键点
- 应用移动平均滤波减少抖动

#### 3. 几何计算器 (GeometryCalculator)
- 计算关键点间的欧氏距离
- 结合比例系数转换为真实尺寸
- 使用经验公式估算围度（胸围、腰围、臀围）
- 区分直接测量项与估算项

#### 4. 尺码推荐器 (SizeRecommender)
- 基于预设尺码表
- 综合考虑胸围、肩宽、身高、腰围、臀围
- 智能匹配最佳尺码
- 支持宽松版/修身版推荐

#### 5. 可视化器 (Visualizer)
- 实时显示测量数据
- 绘制测量线和骨架
- 雷达图展示体型分析
- 提供直观的用户界面

## 快速开始

### 环境要求
- Python 3.7+
- 摄像头设备
- A4 纸/身份证/银行卡（作为参照物）

### 安装依赖
```bash
pip install -r sdkconfig/requirements.txt
```

### 运行程序
```bash
python main/main.py
```

### 使用步骤
1. 启动程序后，将 A4 纸、身份证或银行卡贴近胸前
2. 系统自动检测参照物并完成校准
3. 站在摄像头前，保持自然站姿，微微张开双臂
4. 系统实时显示测量数据和推荐尺码
5. 按 `s` 锁定当前结果并生成尺码建议
6. 按 `r` 重新校准，按 `c` 返回扫描模式，按 `q` 退出

## 技术原理

### 1. 比例系数计算
```
真实长度 = 像素长度 × 比例系数 (K)
K = 参照物真实宽度 / 参照物像素宽度
```

### 2. 人体关键点
MediaPipe Pose 提供 33 个关键点：
- 点 0：鼻尖（用于身高计算）
- 点 11-12：左右肩（用于肩宽）
- 点 13-16：左右肘和手腕（用于臂长）
- 点 23-28：左右髋、膝、踝（用于腿长）

### 3. 尺寸计算公式
- **肩宽**：左右肩点距离 × K
- **臂长**：(肩膀→手肘 + 手肘→手腕) × K
- **腿长**：(髋部→膝盖 + 膝盖→脚踝) × K
- **身高**：(鼻尖→脚踝垂直距离) × K × 校正因子
- **胸围**：肩宽 × 1.1 × 1.1π（椭圆拟合法）
- **腰围**：肩宽 × 0.65 × π × 1.1
- **臀围**：臀宽 × π × 1.2

### 4. 体型分析（雷达图）
雷达图展示 5 个关键维度：
- 身高（150-180cm 范围）
- 肩宽（35-55cm 范围）
- 胸围（75-120cm 范围）
- 腰围（60-100cm 范围）
- 臀围（80-120cm 范围）

### 5. 尺码推荐算法
基于多维度评分系统：
- 身高匹配度
- 胸围匹配度
- 腰围匹配度
- 臀围匹配度
- 肩宽匹配度

推荐输出格式：`L（宽松版）/ XL（修身版）`

## 注意事项

### 使用环境
- 确保光线充足，避免背光
- 背景尽量简洁，避免复杂图案
- 摄像头与身体保持适当距离（1-2 米）

### 测量姿势
- 参照物应与身体测量部位在同一平面
- 保持自然站姿，双脚并拢
- 身体正对摄像头，避免侧身
- 微微张开双臂，便于 MediaPipe 检测

### 精度优化
- 多次测量取平均值
- 定期重新校准
- 使用较大尺寸的参照物（A4 纸优于银行卡）

## 常见问题

### Q: 摄像头无法打开？
A: 检查摄像头驱动，确认摄像头权限，尝试更换 CAMERA_ID。

### Q: 参照物检测失败？
A: 确保光线充足，参照物清晰可见，避免背景干扰。尽量使用 A4 纸而非银行卡。

### Q: 测量结果不准确？
A: 重新校准，调整参照物位置，确保与身体在同一平面。检查光线条件。

### Q: 姿态检测不稳定？
A: 改善光线条件，调整摄像头角度，保持稳定站姿，微微张开双臂。

### Q: 身高估算偏大/偏小？
A: 身高是通过鼻尖到脚踝的距离估算的，校正因子已优化。如仍有偏差，可在 config.py 中调整 HEIGHT_CORRECTION_FACTOR。
