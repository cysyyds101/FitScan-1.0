GPU 推理专用 · Linux

Inference API
FastAPI 推理专用
只做 GPU 推理，无业务逻辑。接收 HTTP 请求，调用 PyTorch 模型，返回 JSON 结果。
Model 1
人体测量模型 /infer/measure
输入深度数据 → 输出精确身体尺寸（肩宽、胸围、腰围、裤长等）
Model 2
3D 模型生成 /infer/generate
输入照片/扫描 → 输出 GLB 模型 URL。底层可用 Tripo3D / MNISTR3D 等。
Access Pattern
FastAPI monolith → POST /ai/measure（httpx 调用）
FastAPI monolith → POST /ai/generate（httpx 调用）
