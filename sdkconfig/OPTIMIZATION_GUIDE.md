# FitScan 算法优化指南

## 📋 环境优化清单

### 1. 硬件环境

#### 摄像头设备
- **推荐配置**：
  - 分辨率：1920x1080 (1080p) 或 3840x2160 (4K)
  - 帧率：30fps 或 60fps
  - 对焦：自动对焦或手动对焦
  - 镜头：广角镜头（90-120度）

#### 计算设备
- **CPU**：Intel i5/i7 或 AMD Ryzen 5/7 及以上
- **内存**：8GB 或以上
- **GPU**（可选）：NVIDIA GTX 1060 或以上

### 2. 软件环境

#### Python环境
```bash
# 创建专用虚拟环境
python -m venv venv
venv\Scripts\activate

# 升级pip
pip install --upgrade pip
```

#### 依赖库安装
```bash
# 安装优化版本
pip install opencv-python==4.13.0.92
pip install mediapipe==0.10.33
pip install numpy==2.4.3
pip install Pillow==12.1.1
pip install scipy==1.17.1
```

### 3. 算法参数优化

#### 参照物检测优化
- **降低检测阈值**：提高检测成功率
- **扩大匹配范围**：适应不同光照和角度
- **多特征融合**：面积、长宽比、矩形度综合评分

#### 姿态估计优化
- **模型复杂度**：使用模型复杂度1（平衡精度和速度）
- **检测置信度**：0.5（平衡检测率和误检）
- **跟踪置信度**：0.5（确保跟踪稳定性）

#### 几何计算优化
- **多关键点平均**：提高测量稳定性
- **加权滤波**：最新数据权重更高
- **校正因子调整**：根据实际测量结果微调

### 4. 使用环境优化

#### 光照条件
- **均匀光照**：避免强光直射或阴影
- **背景简洁**：使用纯色或简单图案背景
- **对比度适中**：确保参照物清晰可见

#### 拍摄姿势
- **正对摄像头**：身体与摄像头垂直
- **参照物位置**：放在胸前，与身体同一平面
- **距离适中**：1-2米距离，确保全身可见

#### 参照物选择
- **A4纸**：21.0cm × 29.7cm（推荐）
- **银行卡**：8.56cm × 5.4cm
- **其他**：任何已知尺寸的矩形物体

### 5. 性能优化

#### 实时处理
- **降低分辨率**：在保证精度的前提下降低分辨率
- **跳帧处理**：每2-3帧处理一次
- **多线程**：图像采集和处理分离

#### 内存优化
- **及时释放资源**：使用完毕后立即释放
- **避免重复计算**：缓存中间结果
- **批量处理**：减少频繁的内存分配

### 6. 精度提升技巧

#### 多次测量
- **连续测量**：连续测量5-10次
- **取平均值**：计算平均尺寸
- **排除异常值**：去除明显不合理的测量结果

#### 校准验证
- **定期重新校准**：每次使用前重新校准
- **验证比例因子**：检查比例因子是否合理
- **对比已知尺寸**：用已知物体验证测量精度

#### 环境一致性
- **固定位置**：每次测量使用相同位置
- **相同光照**：保持光照条件一致
- **稳定参照物**：使用相同的参照物

### 7. 故障排除

#### 校准失败
- 检查参照物是否清晰可见
- 调整光照条件
- 更换参照物或位置
- 降低检测阈值

#### 测量不准确
- 重新校准系统
- 检查摄像头分辨率
- 调整拍摄距离和角度
- 使用更高质量的参照物

#### 性能问题
- 降低图像分辨率
- 减少处理帧率
- 关闭不必要的可视化
- 使用GPU加速（如果有）

### 8. 高级优化

#### GPU加速
```bash
# 安装CUDA版本（需要NVIDIA GPU）
pip install opencv-contrib-python-cuda

# 或使用TensorFlow GPU后端
pip install tensorflow-gpu
```

#### 模型优化
- **模型量化**：减小模型大小
- **模型剪枝**：移除不必要的参数
- **知识蒸馏**：使用小模型学习大模型

#### 算法改进
- **深度学习**：使用深度学习替代传统算法
- **多摄像头**：使用多摄像头提高精度
- **3D重建**：从多角度重建3D模型

## 🎯 预期效果

通过以上优化，您可以获得：
- **更高的检测精度**：参照物检测成功率 > 95%
- **更准确的测量**：尺寸测量误差 < 5%
- **更快的处理速度**：实时处理帧率 > 15fps
- **更好的用户体验**：稳定、流畅、准确
